## 本轮变更

- 图片等待：C 版银蓝微粒聚拢、停留、舒展，原生 Canvas、30fps 上限；后台/离屏暂停，减少动态效果及低电量静态显示。线上 `imageWaitParticles`、`imageWaitParticleCount`、`imageWaitCycle` 可调整开关、数量和周期。
- 会员：统一到期校验，空日期、异常日期和到期边界拒绝访问。登录、聊天、图片入口共用相同判断。客户端显示到期原因，额度耗尽保持登录，提供查看额度/续费动作。
- 图片额度：缺失、异常额度配置拒绝调用；已用完或余额全部预留时不再开始新任务。POOL_EXHAUSTED 是不可自动重试的业务状态，不再误映射为服务器错误。
- 原素材替换：请求校验识别“原Logo+替换”关系，缺失原素材合成参数时回注 Agent 修正，在调用生图之前阻止相似Logo重绘。前置模型获得授权的一张压缩生成图预览，用于估计替换区域。

## 保留的实际边界

- 前置模型仍可能首轮漏参数；校验反馈负责自动纠正，不承诺每次零重试。位置估计存在视觉误差。
- 记忆采用已有文本/图片说明检索及 Agent 多查询，不是无限上下文或全量向量语义记忆。历史图片可按返回的原件ID取用，不把所有图片每轮上传。
- 现有全局存储桶仍有历史公开对象；新文件私有，已迁移文件和访问时迁移受控，不宣称历史全桶迁移完成。
- 服务端可调模型、路由、提示规则、额度与动效参数；新增原生能力或协议字段仍可能需要更新 App。
- 随机出图审美、人像一致性、内容完整性不能由编译成功证明。最终 IPA 的真实设备体验由用户复核。
