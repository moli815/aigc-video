# 已授权的本次生成图编辑预览

用户明确授权：仅在编辑刚生成的图片时，给当前前置聊天模型发送本次所需的一张压缩预览，用于定位Logo等区域。该授权解除上轮自动审批对这项新增跨服务传图的拦截；不涉及手动执行全环境归档任务。

## 边界与数据流

当前用户编辑意图 → 同会话、当前用户消息之前最近的生成图 → 原有云端素材读取（如本机无副本）→ ImageIO等比缩略及EXIF方向修正 → 当前用户的多模态消息 → 原有聊天接口与前置模型。没有新建LLM接口，没有额外规划调用，也没有更改Seedream请求、原素材合成、auto路由或产物存储。

- 只附加一张生成图预览；长边最多1024像素、JPEG最多350KB，不发送整段生成图历史。
- 显式排除生成图、普通聊天、当前上传原图编辑和全新生图不触发。生成图必须在本会话当前用户消息之前，不使用其他会话数据。
- 标注为“编辑前底图”，不能当成本轮结果；不计入上传素材的source_index。上传附件保留原顺序。
- 当前已有6张多模态图片时不挤掉任何附件，也不追加第7张预览；明确说明无法据预览定位。
- 编辑生成图时不顺带承接无关的历史上传图。云端读取、压缩前后固定账号、会话和会话凭据；取消、删除或账号切换后不发送旧上下文。
- 无法读取或压缩时提示前置模型尚未看清，必要时确认位置，不能假装看过或悄悄换图。
- 不持久保存base64，不在日志记录原图、预览或提示词。

## 验证

新增意图、比例/体积、EXIF、取消、素材编号、6图上限、真实上下文接线、非编辑请求、跨账号与损坏图片等回归。由iOS测试导出实际消息与工具定义，使用纯色合成海报/Logo进行真实前置模型契约测试；不使用客户照片。之后等待完整CI并下载对应IPA。粒子等待动画仍只保留HTML预览。
