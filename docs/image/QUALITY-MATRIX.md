# 图片质量测试矩阵（pro_only 阶段）

现状：`IMAGE_ROUTING_MODE=pro_only`，所有图片任务固定 `doubao-seedream-5-0-pro-260628`。
组图（image_series）在 Pro 下**明确拒绝**（422 `TASK_UNSUPPORTED`），不调用模型、不扣费、不降级。

## 记录字段（每项都填）

| 字段 | 说明 |
|---|---|
| 实际模型 | 服务端 `image_route` 日志 / 响应 `model` 字段 |
| HTTP | 200 / 409 IN_PROGRESS / 422 TASK_UNSUPPORTED |
| requestId | 幂等与扣费核对用 |
| taskKind | generate / edit / poster / decompose / series |
| qualityTier | high（pro_only 下恒为 high） |
| aspectRatio | 如 16:9 / 3:4 |
| references | 参考图张数（编辑必须 ≥1） |
| 是否重试 | 视觉复核 / 质量失败各最多 1 次 |
| 总耗时 | s |
| 是否裁切 | 对比原图比例 |
| 人物是否变形 | 换装/合成场景必看 |
| 背景是否漂移 | 只改背景场景必看 |
| 是否出现模型文字 | 名片/海报底图必须"零文字" |
| 是否重复扣费 | 对照 `bf_usage_logs` 同一 requestId 条数 |

## 素材需求（一次给齐，集中测完）

1. 一张横版照片（≥1920×1080）
2. 一张竖版照片（≥1080×1920）
3. 一张正脸人像（背景干净）
4. 一张待编辑原图（用于"只改背景/换装"）
