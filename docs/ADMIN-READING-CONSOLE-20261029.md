# 深色阅读管理台：功能整理与发布说明

## 第二轮视觉调整

根据用户实测，第一版字号和按钮偏大，会员标签换行时挤在一起。本轮改为默认16px正文（可选18/20）、1.65倍行距；旧阅读偏好降一档迁移，新偏好保存版本号。常规按钮缩小，移动端仍保留适合点击的高度。

会员标签采用独立flex布局和8px间距；月额度突出剩余金额、百分比、渐变进度条，≤50%提示留意、≤20%提示偏低、≤0提示用完；未知额度不猜值。到期7天内单独高亮。

工作台增加4个关键指标、真实账单的最近7天支出趋势、到期/低额度/同步状态提示。日期未同步时标为待同步，不冒充零支出。客户统计仍只覆盖当前接口返回的最多200人。

侧栏与指标采用 Lucide 线性图标，来源 `https://github.com/lucide-icons/lucide`，图标保存在 `web/admin-icons-20261029.svg`，ISC许可保存在 `web/licenses/lucide.txt`。只用本地资源，不引入运行时CDN。深蓝灰面板、柔和渐变与青绿/浅蓝/琥珀色强调增强层次；没有动态闪烁。

本轮发布前备份是 `outputs/pre-compact-admin.html`、同前缀CSS/JS及 `outputs/admin-compact-before.json`。回滚需恢复这3个文件，而非只恢复HTML。新网页通过资源查询参数 `v=2` 避免旧缓存混版。第二轮默认字号与本段为准，下文第一轮记录保留供回溯。

## 本次目标

管理员更容易找到常用操作、看清金额并调整 AI 服务。仅调整管理员网页；没有改 App、员工页、共用登录页或云函数，也没有修改线上业务配置和计费规则。

## 功能取舍

| 日常入口 | 保留的任务 |
|---|---|
| 工作台 | 待审核数量、当前客户列表中7天内到期人数、30天官方应付、四项常用操作 |
| 客户与会员 | 搜索当前列表、编辑、续费、日周额度；开通审核与发放记录快捷入口 |
| 账单与用量 | 两平台应付、调用成本估算、用户额度扣减；产品、日期、官方账单、按用户/订单查调用、CSV |
| AI与出图 | 默认6项常用配置，按模型、出图/记忆、计费/限流、技术/密钥分类；全局搜索；按组保存 |
| 套餐与收款 | 套餐售价、额度、可见性、收款码及已有功能开关 |

“更多管理”保留开通审核、发放记录、员工账号和专家/开场白编辑。旧版兼容字段、底层端点和高级 JSON 不再默认铺满页面，仍可从分类或全部配置进入。没有删除生产能力或数据。

客户列表合并为5列。编辑、续费直接可见；重置密码、停用、删除收进“更多操作”，原确认和事件委托保持。列表搜索仅搜索当前接口返回的数据（最多200人），不假称全库搜索。工作台的到期人数也明确标为当前列表。

## 阅读设计

- 石墨灰 `#14181C`、深灰面板 `#1C2227`、浅灰文字 `#E4E8E7`、柔和青绿 `#80CFBB`；没有背景动画和大面积渐变。
- 正文默认18px、1.75倍行距，左对齐、短句与分块；右上角可选18/20/22字号、舒适/更宽松行距，仅保存在本浏览器。
- 常规按钮至少48px高，有文字；当前导航同时使用文字、底色、边线指示，不只依靠颜色。
- 财务摘要两位小数；精确小额费用仍在明细、金额说明和导出中保留，不改变金额。
- 弹窗添加语义、键盘焦点限制与关闭后返回；未打开弹窗不可通过Tab聚焦。

参考：[Dyslexia Scotland 阅读格式建议](https://dyslexiascotland.org.uk/dyslexia-friendly-typed-formats/)、[LiteLLM 管理界面](https://docs.litellm.ai/docs/proxy/ui)、[Langfuse 用量与成本](https://langfuse.com/docs/observability/features/token-and-cost-tracking)。阅读建议强调间距、行长、结构和个人偏好；深色来自用户明确偏好，不宣称它适合所有阅读障碍者。中文沿用系统熟悉字体，没有强制安装特殊英文字体。

## 同时修复的前端问题

1. 保存一个配置分组时，原代码清空整个 `CFG_DIRTY`，导致其他组草稿消失。现在只删除本次提交字段；搜索和分类切换保留草稿。
2. 原 API 包装在 HTTP 失败而 JSON 缺少 `ok:false` 时可能按成功处理。现在同时检查 HTTP 状态和业务状态，错误明确呈现。
3. 异步账单调用切换用户/页面时，用请求序号与目标节点检查避免旧结果覆盖新结果。
4. 隐藏弹窗原来只透明，不阻止键盘聚焦；现补 `visibility` 与焦点管理。关闭状态按 Escape 不再跳到旧按钮。

配置类型、范围、风控与验证仍以 `/admin/settings` 的后端 schema 为准。前端分类仅整理显示，没有另写一套业务校验。供应商密钥继续仅显示掩码、留空不改；真实秘密不进入网页源码。
