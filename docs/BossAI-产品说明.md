# BossAI 当前 App 产品说明

日期：2026-10-06；build：2026100604；源码提交：`816d2f9efccf9ffc95c872f2324cf4bd2c551cf9`。本文依据当前源码与原生验收记录，不使用历史营销描述作为已实现证据。

## 定位与范围

BossAI 是面向经营者的 iPad 任务工作台。用户描述目标和约束、上传资料，调用顾问的工具，核对外部证据，获得可以阅读、复制或导出的交付。线下课程、服务商/代理机制、商业包装不属于当前 App 的必需功能；账号、订阅、团队协作服务端和真实业务转化数据在材料中未体现。

当前有10位经营顾问和通用对话，共11个角色。角色契约包含输入要求、技能、工具权限、工作流、交付要求和边界。专业能力按具体工具和任务验收，名称或章节齐全不等于专业判断正确。

## 功能与用户路径

| 功能 | 当前行为 | 限制 |
| --- | --- | --- |
| 首页任务工作台 | 三类任务卡和专家卡；填写模板进入草稿，发送才建立会话 | 尚无完整任务进度、任务类型筛选与协作 |
| 专家技能 | 横幅打开技能说明；具备计算器的角色提供计算工作台 | 部分角色仍主要执行结构与流程检查；没有专业数据库授权的证据 |
| 可靠经营计算 | 加权决策、单位经济、营销漏斗、股权稀释、现金续航、平率提成、演讲时长；验证输入并返回公式 | 数学结果受输入和假设约束，不能单独证明经营或法律结论 |
| 模式与深度 | 自动核实、联网研究、仅用现有资料；清晰简答、详细分析 | 自动判断为关键词启发式；用户可显式选择。仅用现有资料仍调用所选远程模型 |
| 搜索和阅读 | 可选API增强源及多HTML/RSS引擎；SwiftSoup按结果容器提取并读取正文；有限候选排序 | 引擎会反爬；摘要日期未经事实核验；验证码、超时和无命中还缺明确分类 |
| 证据边界 | 每任务最多12个唯一查询、32000字符证据、单份12000字符；最多8轮模型请求；重复查询复用 | 字符不是token；不是全会话总上下文预算；达到上限会报告缺失 |
| 答案和引用 | 仅最后无需工具的一轮作为最终答案；来源按引用编号；正文完整展开、复制、用户手动折叠 | 模型仍可能生成无效引用，展示保留未知警示；字段级证据映射尚未完整实现 |
| 表格和Markdown | 完整行数，换行撑高；宽表横向查看；后台解析缓存和流式节流 | 极大表、复杂CommonMark和嵌套列表仍需专门验收 |
| 本地资料 | 导入文字、PDF、Office和图片OCR；资料库筛选、搜索、预览、分享 | 专业检索只看近200份文档的前20000字符；缺分块、FTS和页段出处 |
| 文件交付 | Word、Excel、PPT、PDF存入本机资料库 | 复杂版式和专业模板有限；不能把文件格式有效等同业务内容正确 |
| 图片 | 生图服务调用、后台缩略图、持久化 | 长历史原图Data仍可能增加内存；未接入Nuke |
| 记忆 | 自动提取与本机保存，可删除 | 缺完整人工确认、来源和失效策略；提取请求会发送必要上下文至模型 |
| 主题 | 六套动态明暗底色、标题字体、密度/形状/阅读宽度 | 仅专家横幅白字对比度有本次自动门槛，整App大字体和真机分屏待测 |
| 预算与备份 | 请求边界、token费用估算、加密备份与合并恢复 | 费用是估算而非账单；大规模恢复与长期磁盘/内存需真实资料验证 |

## 模型和数据边界

App对外身份为 BossAI，不冒称固定的其他模型。服务商请求适配与研究流程分开；更换兼容模型无需改搜索、引用、公式和UI，非兼容协议仍需适配。DeepSeek默认快速模式是其协议参数选择，高级思考模式开关及跨用户轮次思考持久化当前未实现。

对话、文件、记忆和凭证的持久化在本机；联网搜索、模型、OCR以外的生成服务会进行相应远程请求。不能据此声称所有数据从不离开设备。“仅用现有资料”只禁用网页检索，当前没有本地模型推理运行时。
