## 安装专项

苹果建议分别验证全新安装和保留旧数据更新。测试走同一台新 iPad 模拟器和同一个应用标识。旧版实际源码来自上次成功分发构建。在旧宿主的持久化 SwiftData 库写入一段对话、一条关联消息、一条账号记忆，再通过应用的 FileStore 写入一份附件。候选覆盖安装后检查所有权、消息关联、文件元数据和原始字节。两个版本分别从普通登录入口启动。过程使用合成资料。[Apple 发布构建测试指南](https://developer.apple.com/documentation/xcode/testing-a-release-build) · [上次分发构建](https://github.com/moli815/aigc-video/actions/runs/45163495051)

Mac 上可将此仓库检出至候选提交，在有空白 iPad 模拟器、Xcode 和 XcodeGen 的环境运行 `bash qa/install-upgrade/check.sh`。旧版本通过原仓库只读下载。人工分发仍要单独确认实际签名、客户设备系统版本和现有安装身份。
