## 4. 官方与社区：用什么，不照搬什么

### 官方 5.5 契约（11-16 查阅）

- [火山官方 5.5 教程](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh)：国内 ID `doubao-seedream-5-5-261028`；最多10张参考图；增强多轮编辑，但仍需将上一轮图传回，并说明改什么、保留什么。
- 原生 RGBA：`background:transparent` + `output_format:png`，可以没有透明输入图。我们当前外部 HTTP 主生成未暴露完整 background 契约，**模型具备不等于用户工具具备**；不要暗示已接入抠图成品链路。
- 拆层：底图 + 最多99层，`layer_decomposition_options.max_images` 为2–100；`text_recognition:true` 返回规整文字层的内容、位置、近似字体样式。艺术字/手写字不在保证范围，字体为相似结果。用户此前明确暂不接腾讯 OCR，保持该约束，不再索要 IAM。
- [图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)：5.5 可用 1K/1.5K/2K；也可显式宽×高，总像素 921600–4624220、宽高比1/16–16。**21:9 不是更多总像素；它改变布局空间。**不能宣称只拉长比例便解决千字。
- [通用生成教程](https://docs.volcengine.com/docs/ark/image-generation-tutorial?lang=en) / [提示词指南](https://docs.volcengine.com/docs/ark/seedream-4-0-5-0-prompt-guide?lang=zh)：建议视觉指令简短、可见原文引号化、明确编辑边界。后者列出的适用模型为4.0/4.5/5.0 lite，不能冒称5.5专属实测指南。千字正文保留为内容契约，不把所有聊天记录塞进视觉 prompt。
- 5.5 不接受 fast 提示词优化；当前能力表 `fastPromptMode:false` 是正确方向。透明、拆层、分辨率与多图上限应在付费前校验。境外 BytePlus 的 `dola-` ID 与国内 `doubao-` 不能混用。
