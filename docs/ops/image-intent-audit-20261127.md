## 参考实现

ComfyUI 的 Seedream 5.5 编辑流程将输入图按连线顺序交给供应商。结合火山方舟官方 5.5 文档，明确说明本轮要改和要保留的部分，以及素材来自哪张参考图。5.5 API 最多支持 10 张参考，安装包独立素材上限 6 张来自 App 的传输契约。沿用项目中的 Swift 兼容字段和 Node.js 服务。未引入 ComfyUI 的 GPL-3.0 代码、Python 和其他依赖。[ComfyUI 示例](https://comfy.org/hub/workflows/seedream-5-5-image-edit-f772190f7ce5/) · [开源许可证](https://github.com/Comfy-Org/ComfyUI/blob/master/LICENSE) · [火山方舟 5.5 教程](https://docs.volcengine.com/docs/ark/seedream-5-5?lang=zh) · [图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en)

## 问题、修复和证据

| 场景 | 根因与候选修复 | 验证及边界 |
| --- | --- | --- |
| 长聊后说「按前面谈的做一张海报」 | 旧包把当轮原话和 OCR、编号图册提示装在一起。同步库只存原话。历史匹配此前使用合并文本，还排除了短指令。沿用原话提取器，匹配最新原话和至少一个较长的不同历史锚点，查找唯一同账号会话。 | 200 条记录样例叠加强制上下文压缩。早期名称及第 150 条更正都进入规划输入，后续记录和其他账号数据未混入。冻结包发送近 40 条，云端回看仍要求同步到位。首 50 条与近 100 条之间的超长会话资料仍可能遗漏。 |
| 一次给 4–6 张图 | 已有 image_plan 时跳过明确的全量附件；旧规则又可能按面积猜错素材角色。全量指令补齐附件，并将保护索引从旧发送槽位映射到实际选择。移除依据面积推定 Logo、自动指定照片作主视觉。 | 4、5、6 张被逐张送入供应商请求，顺序匹配。现有图像保护路径按自身允许的角色合成。请求到达供应商不代替视觉和小字验收。 |
| 一次给 7–8 张图 | 旧版图册通道可提交整组，规划返回第 7 或 8 张独立索引会被 IPA 拒绝。全量请求用现有图册通道，去掉越界选择。 | 7、8 张均以一张编号图册送入供应商模拟请求。用户只选第 7 或 8 张单独当底图时，当前 IPA 的独立索引限制依旧存在。 |
| 指定位置加原 Logo | 旧分支只认特别固定的句式，按面积也可能认错图。对明确角落，绑定上次成图或两份明确编号的本轮原件，保留原版面，验证框落在用户指定区域。生成版缺少实际预览时需选定或补传底图。 | 检查错误角落拒绝、两附件逆序绑定、旧包局部合成字段。底图和 Logo 的实机合成外观待验证。 |
| 换风格并加 Logo | 旧分支附加默认浓艳配色。纯风格修改用用户给出的风格，并保留原稿文字。由 5.5 合作设计时传原稿与 Logo 两张图，角色明确。仅加 Logo 时按旧包实际流程用原件合成。 | 隔离请求确认写意风格与 Logo 槽位。未用付费样图证明 Logo 像素、去底或成品。 |
| 「标题正下方、日期左侧」加小圆点 | 现有局部编辑请求保留相对位置和原图。 | 隔离请求未切换整图重绘。成品像素和元素关系需隔离实图对比。 |

## 补充：前置规划看图

旧 `handleChat` 扫到图像时，有一个最高档分支在找到兼容视觉模型后仍选回原模型。模型判断也不接受官方 `deepseek-flash` 名称。两种情形都可能导致后续规划把素材认错。修正为主模型可看图则保留，否则实际改用同提供商配置的视觉模型。火山方舟支持视觉分类、定位和多图输入。DeepSeek 官方的 `deepseek-flash` 接受图像输入及兼容接口。物料阅读与工具规划保持同一次调用，未新增通用识别调用和依赖。[方舟图片理解](https://docs.volcengine.com/docs/ark/image-understanding?lang=zh) · [DeepSeek Vision](https://api-docs.deepseek.com/guides/vision/)

对四组候选实际 `/api/chat` HTTP 入口做上游捕获。官方 Flash 别名、项目现用版本式别名、兼容视觉回退都保有 2 个有序 `image_url`。视觉配置与提供商不符时保留文字备注，系统提示明确模型没收到图片像素。各组均只有一次规划调用，账务元数据记录实际请求的模型名。测试只捕获请求，无付费出图或实图识别结果。新增规则用于用途和位置识别，原样直传仍保留原有契约。候选未发布，回滚取 `7b0341187cae83b4f150594b8feae2d7c9a36954`。
