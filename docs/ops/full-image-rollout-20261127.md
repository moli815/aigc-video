# 2026-11-27 生图主链路与精准编辑

## 源码根因

精简简报生产读取只发生在海报分支。局部编辑之前只纠正部分删除请求。复测样例中，前置模型把右上改成左上，还把保留的橙线列为删除目标。该错误发生于发给 Seedream 前。

## 入口、触发条件和兜底

| 请求 | 执行条件 | 处理方式 |
| --- | --- | --- |
| 普通生成、参考生图、普通组图 | Seedream 5.5，服务器签发的简报与素材数量一致 | 本轮原话、顺序与用途、相关确认信息及定稿文字。用户委托时补充自适应视觉方向。普通图保留合适留白，商业画布按内容提升密度。组图子任务保留各自编号和构图差异要求 |
| 明确局部编辑 | 有明确动作和区域或明确更改范围，能绑定当前附件或会话底图 | 保留用户原话，清除前置定稿、布局和比例猜测。附件重新排序时附上实际对应关系 |
| 编辑范围模糊或底图缺失 | 缺少明确动作或区域，或来源校验找不到底图 | 兼容规划和既有来源校验。缺失素材按现有入口提示补齐 |
| 保护品牌原件、明确逐字排字、图册、画布重排、图层 | 显式交付要求或素材工作流生效 | 保留素材授权、准确交付及分层约定 |
| 兼容兜底 | 开关关闭且未获灰度，旧请求无新简报，非 5.5，素材不匹配，超出简报适用范围 | 保持原有路由与幂等账务。已选有效主路径时禁止为同一请求追加付费的旧方案 |

IMAGE_COMPOSITION_POLICY.imageBriefEnabled 管全量，compactPosterAccounts 用于灰度和回退。旧版已签发的嵌套简报只读兼容。会员 IPA 沿用原接口。广告可以出现贴题的补充宣传语，用户删改时采用局部编辑。生成式修图的像素变化范围用实际成品验收。
