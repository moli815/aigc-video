# P0-1：参考图原文提取（已上线，2026-11-20 13:57:52）

## 问题

同一张产品图，让模型「一边看参考图一边设计文案」时，它会改写术语：
`PGM接口 → PoE接口`、`多防区接口 → 多协议接口`。

## 根因（官方文档）

DeepSeek 的视觉输入按「总像素约 800×800 等量」折算，单张最多 384 token。
1625×1920 的海报喂进去，实际只按缩略图处理，小字读不准，模型就用近义术语蒙混。

## 关键实验

同一张图，只让它「照抄文字」（不做设计）：26 项命中 23 项，剩下 3 项是原图换行
（「智能监控联网 / 报警平台PC端」），**不是识别错误**。

结论：错字发生在「一边读一边设计」这个动作上，不是发生在「读」上。

## 做法

1. `shouldTranscribe()`：有内联图 + 设计类诉求 + 不是「只改一点点」才触发
2. `transcribe()`：调一次视觉模型，只让它逐行抄字（约 4s）
3. `verbatimMessage()`：把抄下来的原文作为「逐字稿」注入 system 消息
4. `repairTerms()`：模型仍写歪时，按「等长 + 首字同 + 末两字同 + 领域后缀」改回逐字稿写法
