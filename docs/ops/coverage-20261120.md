### 用例抓出的两个 bug（已修）

1. **单图角色判定失效**：`if (valid.length < 2) return {…全空…}` 让"单图重绘"完全无法识别角色。
2. **空附件崩溃**：0 张图时走到 `sorted[0].ratio`，抛 `Cannot read properties of undefined`，纯文字需求会 500。

## 集成层（部署后执行）

| 编号 | 场景 | 通过标准 |
|---|---|---|
| E1 | 旧海报重绘 + 三附件 | 比例误差 ≤8%、公司全称在、热线在、0 占位、0 重复 |
| E2 | 餐厅 17 字段 | 6 产品名 + 6 价格 + 品牌 + slogan + 热线 + 地址全对 |
| E3 | 纯文生图 | 出图成功、无占位 |
| E4 | 两轮改稿 | 结构相似度 ≥90%（只改标题，其余基本不动） |

### 执行方式

```bash
node scripts/integration-suite-20261120.cjs --max 2.0
```

脚本会：建临时账号（含品牌记忆）→ 逐条跑 → 每条断言 + 出图落盘 → 累计成本超 2 元立即中止 → 清理临时数据 → 写 `outputs/integration-20261120/results.json`。
