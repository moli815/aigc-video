## 仍需继续做

1. 长文正确性从“每字段原文/含义/数量”对账到实际可见字形。5.5官方拆层富文本OCR可给规整文字位置与近似样式，不能把它的识别结果当事实真值；用原始定稿、真实字体和经过像素门禁的原生区域重排，保持艺术背景。当前真实字体候选还只有旧31字段案例12字段/18片段局部通过，不能全员启用nativeCopy/OpenCV；继续复用已付费图层资料，不盲重做整图。
2. confirmed-image-context.userExcerpts按事实关键词筛选，风格/局部禁止项不含品牌或“更正”等词时可能没有进入原文保护；同会话恢复只取升序前100条，长聊天的中后段最新更正仍有漏召回风险。需要“早期身份+近期更正”的有界并集与归属/时序回归，第一阶段未修改；18:36补丁已按文末补充上线。
3. 当前App源码GeneratedImagePlanningContext.maxPreviewEdge及ImageCompressor.maxEdge为1024，后者JPEG0.78，可能影响密集参考识图；这只是当前源码，不是已寄出IPA版本的认证。ImageService返回原始下载/解码Data，不能把规划预览限制说成最终图必被压成1024。先核对旧包来源与已同步原件可否服务端恢复，再决定是否进下次统一出包，不改App。
4. 商业composer的调色板/布局集合、提示词残留的Pro/Flash质量叫法仍需统一治理；当前实际生图是5.5，旧字段名称不代表另有5.5 Pro。多参考附件重排、Logo像素级原件、任意500字逐字无错仍未在本轮获全量认证。
