# 会员作图请求、旧规则与故障复测

2026-11-24 15:10 北京时间。此记录适用于候选源码。线上发布、模拟器和实机的结论单独记录。

## 现在一条请求怎么走

1. iPad 把当前消息、用户选择的附件及可用工具发往会员聊天接口。普通请求仍由云端结合本轮意图、同账号资料及原件规划。用户指定画风或留白时，它属于用户要求。
2. 明确提出「不要再润色，按下面这段做图」或「原样直传」并给出正文时，API 从本轮真实用户消息提取原文。聊天模型负责工具与素材选择。原文放进旧 iPad 能带回的 structured，图片函数从这个字段取文字。普通规划模型自行填写这个字段时，服务端移除它。聊天史里的旧直传指令只对当轮有效。一个成稿对应单图；多张组图各图的创作规划另走组图接口。
3. iPad 解码工具参数、读取用户选定的照片、上传并展示结果。会员生图跳过本地设计词典、档位与排版决策；编辑未指定新比例时，用实际读取的底图宽高发请求。工具已选定素材来源时，平板不再靠关键词二次改选。已安装的旧包仍可读取 /me 原来的行为字段。设备本地的原件合成、离线自带密钥模式、本地文件导出以及组图的取消、续跑各有实际调用方。
4. 图片云函数仍执行会员检查、额度检查、限流、同请求重放、私有原件归属和交付持久化。普通请求在图片出口编译。直传请求把作者正文直接赋给供应商 prompt，保留段落、引号、空格，关闭本系统的再次润色和改词重绘。文字是否画对需要另外验收。

## 删除理由

| 过去的行为 | 代码证据和处理 |
|---|---|
| 六张卡，两列三行，最多几个字，固定浅色底栏 | bf-api/prompt-contract.js 和 intent-contract.apply 会对部分普通编辑或旧格式输入套第二份模板。去掉该编译器和调用。旧格式定稿由已有 poster-delivery.copyOf 解析，继续送到图片端。 |
| 图像出口尝试再次套模板 | bf-image 的兜底 require 指向当前源码缺少的模块，并尝试给 const 重赋值。整个死分支已删除。 |
| 自动把未指定比例的海报锁成 3:4 | 删除 API 的强制比例。已有明确比例按本轮执行。设备上真实原图尺寸仍用于需要保留画布的编辑。 |
| 会员端从两个开关、关键词与本机词典分别选风格 | 当前会员模式使用服务端作图规划。本机直连模式还有真实用户入口，保留其词典。 |
| 工具规划夹带 fast/Pro 建议 | 图片交付提示移除过时的路由偏好，实际供应商模型由后台配置选取。 |

## 历史证据与复测口径

查询窗口为北京时间 10 月 1 日至 11 月 24 日。腾讯云 bf_sync_v2 中该会员留存的 351 条消息均已扫描，实际最早 10 月 15 日，最晚 11 月 22 日。关键词命中 8 条视觉问题相关消息、2 条比例相关消息，可能重叠。再回顾本项目 Codex 聊天 164 轮的摘要、仓库变更记录、DSH 四天日志及故障样例。报错也可能只显示在终端 UI，库里未出现字样不能视作用户未遇到。原始聊天与客户素材未写入仓库。

| 历史问题 | 本轮复测方式和边界 |
|---|---|
| 无法确认用量、重复收费、额度不足、其他账号串单 | 当前后端套件含成本预留、并发结算、幂等与会员隔离。隔离 HTTP 走重复请求、会员过期和额度耗尽。逐笔供应商最终对账仍是单独财务待办。 |
| 回复中断、空回复、混合工具帧、缺历史原件 | HTTP 回放同一请求的 JSON、标准 SSE、标签 SSE 与混合 SSE。正式工具结构、最后事件、账号归属、缺原件和重试由现行回归覆盖。 |
| 风格被改写、伪标题、空背景、旧比例 | 普通密集与极简请求实际编译了 17 行与 1 行文案。直传真模型隔离调用沿用上轮同一份山城海报成稿；供应商收到的 298 个字符与作者原文逐字相同，返回 2368×1776。费用为作图 0.23 元、前置 0.014724 元的暂估，已删除临时账号。本次未使用客户额度。 |
| 500 字以上文字、Logo、十余件商品、历史对话 | 559 字用例逐行核对至请求出口。此前真实成图的页脚重复与北线产品编号重复尚有反例；本轮直传只验证该成稿，不能代替上述样本目视复验。历史图片未同步时无法复原。 |
| 管理端、记忆、同步、审核与权限 | 回归套件覆盖后台 API/网页契约、租户并发、同步删除、专家工具清单、财务与支付审核路径。真实收款、微信通知、外部供应商最终结算与客户平板安装需独立证据。 |
